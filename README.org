#+TITLE: librnt

A C17 library built with GCC, licensed under LGPL-2.1-only (see
[[LICENSE][LICENSE]]).

Enter the development shell with `nix develop`, then run `make` to
build `build/librnt.a`. The shell provides GCC, GNU Make, and
clangd. Clangd reads the project's `compile_flags.txt` automatically.

The shell's clangd queries GCC for the system header paths, including the
macOS SDK or Linux C library headers. `.clangd` selects GCC as its driver.
After changing the flake, reload direnv (or re-enter `nix develop`) and
restart your editor's clangd server so it uses the shell's clangd executable.

Add C sources to `src/` and public headers to `include/`. Until sources are
added, the build produces an empty archive. Header dependencies are tracked
automatically. Run `make clean` for a fresh build.

Use `make install PREFIX=/your/prefix` to install the library, public headers,
and license. `DESTDIR` is supported for staged installation. Override build
options on the command line, for example `make CC=gcc CFLAGS='-O0 -g -std=c17'`.

Run `nix build` to build and install the library into the Nix store.
