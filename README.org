=librnt= is the C interface for building subsystems atop the RNT
database kernel. It provides the subsystem's side of RNT's native
protocol, as to manage the lifecycle with an initial handle,
discovering kernel objects, and performing operations on them.

The interface brings together named objects and relational data.
Subsystems use handles to navigate directories, manage name bindings,
and work with relations and tuples. Each operation goes through a
common protocol interface, with request and reply types defined for
the protocol being used.

* How to build

Run =make= to build the static library and =make test= to build and
run the tests. A C17 compiler and GNU Make are required. Use
=CC=clang= to select Clang instead of GCC (not recommended).
